id: rb-account-compromise
title: "Runbook: client account compromise"
type: runbook
tags: hacked compromised account takeover unauthorized login security password reset 2fa
---
Trigger: any report of a hacked account, unauthorized posts, or unexpected password resets.

1. Pause all scheduled posts for the client on every platform.
2. Call the verified account owner. Do not act on instructions received only by email or DM.
3. Start the platform's account recovery process with the owner.
4. Rotate the credentials stored in MMC's vault once access is restored.
5. Review activity from the last 7 days and list unauthorized posts, DMs, or setting changes.
6. Remove unauthorized content after the owner confirms.
7. Involve the PR lead if unauthorized content was public.
